🔗 API Endpoints

Available endpoints for your deployed webhook (replace your-domain.vercel.app with your actual domain).

  • POST https://your-domain.vercel.app/webhook
  • GET https://your-domain.vercel.app/health
  • GET https://your-domain.vercel.app/admin/health
  • GET https://your-domain.vercel.app/admin/messages?limit=10

🚀 Quick Setup Guide

1. Deploy to Vercel

  1. Your code is already on GitHub: hypnoticproductions/telnyx-webhook
  2. Go to vercel.com/dashboard
  3. Import the repository
  4. Add environment variables:
TELNYX_PUBLIC_KEY=G/aki61Xy5ZJBt4D3cE8Sa750ahug3tE14PYY/sePSo= RESEND_API_KEY=re_U9wH8VaJ_13SeUZKeKZXCe3GX5p3AmjQs EMAIL_FROM=onboarding@resend.dev EMAIL_TO=richardf.productions@gmail.com

2. Configure Telnyx

  1. Go to portal.telnyx.com
  2. Navigate to Messaging → Messaging Profiles
  3. Set Inbound Webhook URL to: https://your-vercel-app.vercel.app/webhook

3. Test It!

  1. Send an SMS to your Telnyx number with a code like "582941"
  2. Check your email for the HTML notification
  3. Visit https://your-domain.vercel.app/admin/messages to see stored messages
